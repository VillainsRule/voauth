  <h1>voauth</h1>
  <h3>the unified auth system for (most) of my projects</h3>
</div>

<br><br>

if you want to selfhost one of my projects, you are able to create apps on [voauth.villainsrule.xyz](https://voauth.villainsrule.xyz). you can signup there, make an app, and use those credentials inside of the app.

<br>

however, if you'd like to own everything locally (for some reason), here we go...

1. clone the repo
2. install deps from the root project dir
3. add an `RP_ID={voauth instance hostname}` to `api/.env`
4. run `bun .` (node also supported)
